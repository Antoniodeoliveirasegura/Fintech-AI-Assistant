# Demo Assets

This folder is reserved for portfolio demo media.

Recommended files:

```text
docs/demo/demo.gif          # 10-15 second walkthrough
docs/demo/demo.mp4          # Optional higher-quality video source
```

Suggested flow:

1. Login with any valid email and a 6+ character password.
2. Show the dashboard loan hero, live activity, and recent payments.
3. Open Payments and switch filters.
4. Open AI Assistant and ask "What should I do next?"
5. Toggle dark mode from the dashboard app bar.

Keep GIFs under 5 MB when possible so GitHub renders quickly.
